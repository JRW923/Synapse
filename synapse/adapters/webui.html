功能指引

  • 发送任务：底部输入框，Enter 发送，Shift+Enter 换行。
  • 会话：左侧「会话」列表可恢复、删除或清空历史会话；「新会话」清空当前。
  • 待办：左侧展示 Agent 维护的任务清单（待办 / 进行中 / 完成）。
  • 工作区：左侧展示模型、规划模式、Token 预算占用等运行状态。
  • 运行评分：每次任务结束展示安全 / 过程 / 质量 / 效率四维度评分。
  • 压缩上下文：输入框旁「压缩」，或发送「压缩一下」/ /compact。多次压缩后会建议新开会话。
  • 上下文报告：运行结束后可展开查看区块引用率热力表。
  • 设置：首次填入 API Key；也可在此切换模型与规划模式（本会话）。
  • 连接本机：把网页任务派发到本机工作区执行。
  • 主题：顶栏切换亮色 / 暗色，并记住你的选择。
