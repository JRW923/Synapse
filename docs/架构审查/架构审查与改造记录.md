# Synapse 架构审查与改造记录

## 审查结论

Synapse 的核心价值在于将 Agent Loop、工具授权、上下文、记忆和评测置于明确的协议边界内，而不是简单封装模型 API。当前架构适合继续以 Python 演进，不需要为了语言统一进行全量 TypeScript 重写。

## 已验证优势

- Protocol、IoC 和 EventBus 分离了生命周期、实现策略与横切观测。
- Action-time 授权、工作区边界、进程树回收和审计覆盖了工具调用的关键风险点。
- 分层记忆、上下文预算和恢复校验面向仓库级长任务，而非单轮问答。
- Completion Gate、外部 grader、冻结 manifest 和配对实验将“完成”转为可审计事实。

## 主要边界

| 领域 | 当前边界 | 后续方向 |
|---|---|---|
| 沙箱 | 默认是进程树治理，不是完整文件系统隔离 | 在受控容器环境取证并强化隔离。 |
| 注入防御 | 工具输出已扫描签名并中和伪造信任标签；检测为签名式，非语义级 | 对高风险工具补充真实 LLM 对抗测试。 |
| SSRF | 检查时一次解析，重定向逐跳校验；DNS rebinding（检查与连接间记录翻转）未覆盖 | 传输层固定已解析 IP。 |
| 检索 | 轻量规则与关键词为主 | 以真实长任务数据评估 AST/语义检索。 |
| 多 Agent | 已限制角色与文件作用域 | 补齐冲突合并和工作区全生命周期审计。 |
| 评测 | 工程治理和单题 runner 已验证 | 预算允许时完成多任务、重复的外部对照。 |
| 后台任务 | 进程内 asyncio 生命周期，进程退出即终止（刻意不做假恢复） | 需要跨进程续接时引入外部任务队列。 |

## 改造记录

- 修复上下文 overflow 未进入真实 Agent 路径、BudgetHistory 只写不读等长任务治理缺口。
- 接通安全事件发射，使 SafetyMetrics 不再长期为零。
- 将外部 Harness 改为 JSON v1 协议，并在 Windows 用 Job Object 回收子进程树，规避 `_overlapped` 初始化失败。
- 将 CLI 渲染从主逻辑中拆出，并补充实时进度、运行评分和友好错误输出。
- 长任务恢复闭环：新增 `modules/checkpoint.py`（临时 index 快照 + `refs/synapse/checkpoints/` 引用 + tracked-only restore）；ReAct 任务起点自动打快照，thrashing 首次触发自动回滚单文件；`/checkpoint`、`/rewind` 命令；对话历史 LLM microcompact（`react.py::_compact_history` 升级为摘要-再-elide，失败回退原行为）；edit 工具 fuzzy 匹配兜底（whitespace-insensitive 唯一命中 + 按行缩进对齐）与自恢复错误消息；TodoStore 绑定 Session 持久化。
- 安全边界强化：`auth.py` 命令检测改为 shlex token 级（`_tokenize`/`_segments`），引号内操作符不再误切、`$()`/反引号/子 shell 触发确认、不平衡引号拒绝；新增 ask/allow/deny 三态规则与会话级签名记忆化批准；`InjectionGuard.guard_external_output` 挂到 web/web_fetch/browser/db 输出；新增 `modules/security/ssrf.py`（私网/环回/云元数据/数字编码 IP/非 HTTP scheme 拒绝 + 重定向 event hook）。

## 维护原则

- 新模块先复用 Protocol、EventBus 和既有配置边界；不绕开授权或评测事实链。
- 每个非平凡改动至少留下一个可运行检查，优先修复共享根因而非单路径补丁。
- 真实能力结论以冻结数据与可信 grader 为准，工程回归不替代外部评测。
