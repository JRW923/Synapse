## 二、可用性 Bug

### P0 真实越权 / 致命
1. shell 审批只查首 token + shell=True（auth.py:220-226,48；sandbox.py:56）→ `echo hi > /etc/cron.d/y`、`cat /etc/shadow` 放行；危险模式大小写敏感子串可绕过
2. DB 只读守卫可绕过：WITH/PRAGMA 前缀写语句（db.py:15,104-111）
3. 粘性取消：`_cancel_requested` 从不重置（react.py:139,143,352）→ 一次 Ctrl+C 永久毒化单例
4. 畸形 tool_call 击穿：`tc["name"]/["input"]` 在 try 外（react.py:461-462）
5. symlink 读穿敏感文件：read 不 resolve，敏感判定基于字符串（auth.py:214-218, file_read.py:40）
6. 配置 env 污染：loader.py:74-76 任意 provider 的 env 覆盖主 key
7. MCP 多 loop 失活（library.py:351-353）；McpToolWrapper 忽略 isError（wrappers.py:66）

### P1 数据/资源泄漏 + 崩溃
- budget_history 每任务一个文件，实测积 283 个（budget.py:107-117）；run-score-log 无限追加（library.py:435-443）
- config 坏文件裸崩（cli.py:852,907,1833）
- Windows Ctrl+C 被吞（cli.py:63-76）、双击硬杀不保存
- server 并发 /run 串分（server.py:191,257）
- chat finally 无 None 守卫（cli.py:1055-1057）
- background 超时泄漏子进程（background.py:61-63）
- Windows job 竞态 + 静默降级（sandbox.py:56-63,178-180）；成功路径关 job 杀常驻子进程（sandbox.py:93-94）

### P2 一致性/正确性
- 三处命令清单不一致（cli.py:1111-1123,1372-1383）
- /model 箭头选择恒从 idx=0 开始（cli.py:1621,2043-2049）
- AgentCompleted 双层嵌套双计（plan_execute.py:133, react.py:632）
- FileWritten 只对 write 不触发 edit（react.py:550）
- deepseek-v4 anthropic 协议带 prompt_caching 可能 400（library.py:175-178）
