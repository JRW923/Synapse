## 评测报告

评测命令会在 JSON 报告旁生成 HTML 和 CSV：

```powershell
python -m synapse eval repo_pytest --report eval-results/repo.json
python -m synapse.eval.visualize eval-results/repo.json
```

报告中的 `pass_at_k`、置信区间、Token、成本和工具成功率需要结合 `verification_status` 解读。工程回归、单题 smoke 与本地适配层均不代表官方 benchmark 成绩。
