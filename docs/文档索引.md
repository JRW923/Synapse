## 评测可视化

评测命令会在 JSON 报告旁自动生成 `.html` 和 `.csv`：

```powershell
python -m synapse eval repo_pytest --report eval-results/repo.json
python -m synapse.eval.visualize eval-results/repo.json
```

HTML 是无外部依赖的自包含 SVG dashboard，界面标签同时提供中文和 English；CSV 保留英文 machine key，并在相邻列提供中文别名，可直接导入 Excel、Python 或其他分析工具。

报告还会记录重复实验的 `pass_at_k`、Wilson 95% 置信区间、Token、cost 和 tool success rate；这些统计不等同于官方榜单分数，尤其是 `official_runner=external` 的 benchmark。
