# MCP 协议支持 — 实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development

**Goal:** 为 Synapse 添加 MCP Client 能力，支持 stdio 和 Streamable HTTP transport，动态注册 MCP 工具到 ToolRegistry。

## Global Constraints
- Python >= 3.11
- `protocols/` imports nothing from `core/` or `modules/`
- `modules/` imports from `protocols/` and `core/exceptions.py`
- 使用官方 `mcp` SDK（`pip install mcp`）
- TDD: test → fail → implement → pass → commit
- 遵循现有 Provider 模式（Protocol → 实现 → Container 注入）

---

### Task 1: McpClient Protocol + Config

**Files:**
- Create: `synapse/protocols/mcp.py`

```python
@dataclass
class McpServerConfig:
    name: str                          # 唯一标识
    transport: str = "stdio"           # "stdio" | "streamable_http"
    command: str | None = None         # stdio: 可执行文件路径
    args: list[str] | None = None      # stdio: 命令行参数
    url: str | None = None             # streamable_http: HTTP URL
    env: dict[str, str] | None = None  # stdio: 环境变量
    timeout: int = 30

class McpClient(Protocol):
    async def connect(self, config: McpServerConfig) -> None: ...
    async def list_tools(self) -> list[dict]: ...
    async def call_tool(self, name: str, args: dict) -> dict: ...
    async def disconnect(self) -> None: ...
    @property
    def connected(self) -> bool: ...
```

### Task 2: McpToolWrapper

**Files:**
- Create: `synapse/modules/mcp/__init__.py`
- Create: `synapse/modules/mcp/wrappers.py`

`McpToolWrapper` 将 MCP tool schema 包装为 Synapse `Tool` Protocol：
- name: `mcp.<server_name>.<tool_name>`
- parameters: 从 MCP toolSchema 转换为 Synapse ToolSchema
- execute: 调用 McpClient.call_tool()
- risk_level: 可配置，默认 READ_ONLY

Tests (2): wrapper_has_mcp_prefix, wrapper_delegates_to_client.

### Task 3: OfficialSdkMcpClient (stdio)

**Files:**
- Create: `synapse/modules/mcp/official_sdk.py`

基于 `mcp` 官方 SDK 实现 stdio transport 的 McpClient。
- connect: 使用 mcp SDK 的 stdio_client 启动子进程
- list_tools: 发送 tools/list 请求
- call_tool: 发送 tools/call 请求
- disconnect: 关闭子进程

Tests (2): connect_and_list_tools (mock mcp server), call_tool_delegates (mock).

### Task 5: McpManager

**Files:**
- Create: `synapse/modules/mcp/manager.py`

管理多个 McpClient 连接的协调器：
- add_server(config) → 创建 McpClient → connect → list_tools → 创建 McpToolWrapper → 注册到 ToolRegistry
- remove_server(name) → 从 ToolRegistry 注销 → disconnect
- 工具命名：`mcp.<server_name>.<tool_name>`

Tests (3): add_server_registers_tools, remove_server_unregisters, tools_have_mcp_prefix.
