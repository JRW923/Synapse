# 本地网页体验（推荐）

Synapse 是**本地 Code Agent Harness**：它读写的是你自己的代码仓库、执行的命令跑在你自己的机器上。因此推荐在**你自己电脑上**运行，而不是部署到某台服务器供他人访问。

Web UI 不是独立服务，而是 `synapse serve` 在你本机起的同一个进程的前端。浏览器打开 `http://127.0.0.1:8000` 即用，agent 仍跑在你本机。

## 为什么是本地优先（而非服务器托管）

- **能调到模型**：你本机有网直连 LLM；放到无出网能力的服务器上调用会直接挂起。
- **操作的是你自己的目录**：Code Agent 的价值就是编辑你本地仓库，「本地目录授权」指的是你机器上的目录，服务器托管则碰不到你的代码。
- **用自己的 Key**：API Key 在页面填写后仅存本机进程内存，不写磁盘、不共用别人的 key、不烧服务器主人的额度。
- **安全**：agent 会执行 shell 命令，本地跑只风险自己机器；放到公网服务器等于把生产机交给他人跑命令。
- **不占服务器资源**：避免与已有生产服务争内存（小机有 OOM 风险），也无需做多用户隔离。

## 使用步骤

```bash
# 1. 一行装好 synapse 命令（按供应商选装，pipx 隔离环境）
#    DeepSeek v4 走 Anthropic 协议（即 anthropic SDK）：
pipx install "git+https://github.com/JRW923/Synapse.git#egg=synapse[deepseek]"
#    其它供应商把 deepseek 换成 anthropic / openai / google，多个逗号分隔

# 2. 在本机启动 Web UI（默认绑定 127.0.0.1:8000）
synapse serve

# 3. 浏览器打开 http://127.0.0.1:8000
```

首次打开若未配置模型，页面会自动弹出「设置」面板：填入 **Provider / Model / API Key** 即可开始。Key 仅保留在本机进程内存，重启服务需重新填写。Agent 对你本机文件与命令的每次敏感操作都会弹窗确认。

## 与「服务器在线体验」的区别

[服务器在线体验](服务器在线体验.md) 描述的是**受限可信账号**的服务器托管方案（服务器共享 key + Cloudflare Access 限制），并非多用户隔离、也不能匿名公开。普通用户请使用本文的本地优先方式；只有需要受信任团队内网共享、且已解决出网与隔离时，才考虑服务器托管。
