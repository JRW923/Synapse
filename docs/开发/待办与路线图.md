# Synapse 待办与路线图

## 已完成

- MCP 接入、过程质量闭环、Swarm 文件作用域限制、上下文治理、红队框架、运行时评分和主要 UX 优化。
- 评测治理、外部 Harness 协议、固定数据 manifest、预注册与报告完整性。
- 长任务恢复闭环：Git checkpoint/rollback（任务起点快照 + thrashing 自动单文件回滚 + `/rewind`）、对话历史 LLM microcompact（`history_compaction: llm`）、edit fuzzy 匹配兜底与自恢复错误消息、TODO 随 Session 持久化。
- 安全边界强化：shell 授权改为 shlex token 级解析（引号内操作符不再误切，`$()`/反引号/子 shell 触发确认）；web/browser/db 工具输出经 InjectionGuard 扫描并中和伪造信任标签；ask/allow/deny 三态权限规则与会话级签名记忆化批准；web/web_fetch/browser 的 SSRF 防护（私网/环回/云元数据地址与非 HTTP scheme 拒绝，重定向逐跳校验）。
- SWE-bench 冻结 20 题正式 run：gold-verified 入库门槛 + 三档模型 × 3 次重复 + 外部 grader，详见[评测基线](../评测/评测基线与接入.md)；LLM 网关 5xx 分类为基础设施失败、per-call 延迟记账（commit `f72a31f`）。
- 可扩展性与跨平台：`examples/extensions/` 最小 Provider/Tool 示例与[扩展指南](扩展指南.md)，配套可运行测试证明"零主循环改动"；typed retry classifier 完整落地（auth/invalid_request 快速失败，5xx/超时退避重试，分类进报告）；CI 增加 Windows 矩阵（Job Object/SIGINT 等平台代码纳入回归）。

## 当前优先级

### P1：Aider 跨 Harness 对照

同冻结 20 题、同网关模型、同 grader 下 Synapse vs Aider 配对对比（Aider 已确认支持 OpenAI 兼容网关与同格式 JSONL）。这是把"有数字"升级为"harness 能力证据"的关键实验。注意：Aider 不提供完整 Token/cost 时其结果不进入效率对比，只比功能通过率与延迟。

### P2：能力扩展（README 优先路线同步维护）

- Subagent 委派工具：模型侧 `spawn_subagent` 类工具，探索型子任务在独立上下文窗口执行、摘要回主线；复用 HierarchicalPlanner 的 session.fork 机制，避免主上下文膨胀。
- PreToolUse 钩子：当前 hooks 仅支持只读 PostToolUse 通知；将阻断/改写接入 ActionAuthorizer 决策点，支撑企业自定义合规拦截。
- HTTP 会话持久化：server sessions 为内存态（重启即丢），补持久化与 resume/cancel 端点，与 CLI `--resume` 对齐。

### P2：长任务能力

- 评估 AST/语义检索替代轻量关键词检索的收益。
- 将工作区隔离与 Swarm 合并策略扩展为可审计的端到端流程。
- 持续追踪 Token、上下文压缩与检索命中率，避免优化只改善局部指标。
- 评估 `history_compaction: llm` 的成本收益（摘要调用开销 vs 任务成功率），具备条件时跑 A/B 实验。
- EventBus 时序/DAG 可视化：swarm 的 worker/review/vote 事件流渲染进 HTML Dashboard，强化"可复盘"。

### P2：产品体验

- 提供历史任务浏览和可视化运行证据查询。
- 在不改变事件契约的前提下完善 HTTP/CLI 的进度与错误呈现。

### P3：安全加固残余项

- DNS rebinding 级 SSRF 加固（传输层固定已解析 IP）。
- 对高风险工具补充真实 LLM 对抗测试；当前确定性种子集只用于离线回归。

## 明确不做

- 不自研 tokenizer；继续使用现有估算并在需要精度时由 Provider usage 覆盖。
- 不为了追求功能列表引入未验证的插件、模型路由或复杂 UI。
- 不将自建 adapter 或单题 smoke 表述为官方 benchmark 成绩。
- 后台 shell 任务不做跨进程"恢复"——进程退出任务即终止，虚假恢复比诚实丢失更危险；升级路径是外部任务队列。
