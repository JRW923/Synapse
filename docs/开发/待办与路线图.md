# Synapse 待办与路线图

## 已完成

- MCP 接入、过程质量闭环、Swarm 文件作用域限制、上下文治理、红队框架、运行时评分和主要 UX 优化。
- 评测治理、外部 Harness 协议、固定数据 manifest、预注册与报告完整性。

## 当前优先级

### P1：真实模型多任务评测

在预算允许时执行冻结多任务集上的 Synapse/Aider 成对实验，补齐重复运行、Token/cost、外部 grader、失败分类和统计报告。单题结果不得外推为能力结论。

### P1：安全边界强化

- 将工具输出也纳入 prompt injection 检查。
- 审查 allow-list 命令的间接越权读写与管道执行。
- 对高风险工具补充真实 LLM 对抗测试；当前确定性种子集只用于离线回归。

### P2：长任务能力

- 评估 AST/语义检索替代轻量关键词检索的收益。
- 将工作区隔离与 Swarm 合并策略扩展为可审计的端到端流程。
- 持续追踪 Token、上下文压缩与检索命中率，避免优化只改善局部指标。

### P2：产品体验

- 提供历史任务浏览和可视化运行证据查询。
- 在不改变事件契约的前提下完善 HTTP/CLI 的进度与错误呈现。

## 明确不做

- 不自研 tokenizer；继续使用现有估算并在需要精度时由 Provider usage 覆盖。
- 不为了追求功能列表引入未验证的插件、模型路由或复杂 UI。
- 不将自建 adapter 或单题 smoke 表述为官方 benchmark 成绩。
