# 逐屏演示脚本（面试照读版）

> 用法：从上到下逐「场景」走。每个场景给「操作 → 屏幕预期 → 解说」。解说部分直接念/自然发挥即成面试讲述。总时长约 15–20 分钟，可裁剪。
> 前置（已做完）：`pip install -e ".[anthropic,openai,google]"` + `synapse` 跑过配置向导。

---

## 场景 A｜开场定位（1 分钟）

**解说**：
> 「这是一个协议优先的 AI Agent 框架。核心是一个真正的 ReAct Agent Loop，外面包了上下文工程、动作时安全边界、事件可观测和可复现评测。下面我用一条主线——网页发任务、看安全授权、看可观测数据、再切 CLI 复现和回滚、最后跑评测——把这几块串起来。」

**操作**：打开浏览器准备，终端准备两个窗口。

---

## 场景 B｜Web 启动（1 分钟）

**操作（终端 1）**：

```bash
cd /path/to/demo-repo
synapse web --workspace $(pwd) --port 8000
```

**屏幕预期**：终端打印 `Uvicorn running on http://127.0.0.1:8000`，网页与本地 Connector 同进程启动。

**解说**：
> 「`synapse web` 是单进程模式——服务和本地执行器一起起，免去配对。远程部署则是 `serve` + 用户本机 `connect`，任务在本机跑、密钥不上传。」

**操作**：浏览器打开 `http://127.0.0.1:8000`。

---

## 场景 C｜发送任务 + 实时输出（2 分钟）

**操作（网页输入框）**：输入并回车：

```
把当前目录下 README.md 的第一段改成一句话总结，并运行一下项目里的测试
```

**屏幕预期**：

- 顶部「发送」变「停止」。
- 「模型输出」区流式出现回复。
- 「最近工具」区依次出现「写文件 README.md」「执行命令 pytest」卡片。
- 结束插入「状态：成功 · 耗时 Xs · token … · 工具 N/M 成功」。

**解说**：
> 「这是真正的 Agent Loop，不是单轮函数调用。每次工具调用都实时上屏，SSE 推送。右侧还能看到多 Agent 协作状态——切到 swarm 模式时这里会显示分工。」

---

## 场景 D｜确认授权弹窗（3 分钟，重点）

**操作（网页输入框）**：新任务：

```
在当前目录创建一个新文件 hello.txt，内容为 "hi"
```

**屏幕预期**：弹出确认框，显示 `tool_name` / `risk_level` / 参数摘要，三个按钮：拒绝 / 允许一次 / 总是允许此类。

**操作**：先点「允许一次」。

**解说**：
> 「这是动作时安全边界。写文件、执行命令这类高风险操作，每次都要按风险等级、工作区路径、命令链重新授权。命令链用 shlex 解析——引号里的 `|` 只是参数文本，`$()` 和反引号才会触发确认。」

**操作**：再发一个写文件任务：

```
再创建一个 world.txt，内容为 "hello"
```

**屏幕预期**：再次弹窗（说明「允许一次」不记忆）。

**操作**：点「总是允许此类」。

**解说**：
> 「‘总是允许此类’按操作签名记忆，粒度是 `shell:<首 token>` 或 `<工具>:<父目录>`，和 CLI 的 `ActionAuthorizer` 完全同一套，所以 Web 和 CLI 安全行为一致。这是进程级记忆，重启清空，符合命令行同进程语义。」

**操作**：打开「设置 → 确认模式」，选 `auto`，应用；再发一个写文件任务。

**屏幕预期**：不再弹窗，直接执行。

**解说**：
> 「设置里还能切到 auto 全自动批准，等价于 CLI 的 `--yes`。ask / auto 两种模式覆盖‘每次问’和‘全权同意’两类需求。」

## 场景 E｜停止任务（1 分钟）

**操作（网页输入框）**：

```
写一个脚本，循环打印 1 到 1000000，每打印一个 sleep 0.01 秒
```

**屏幕预期**：任务进行中。

**操作**：点「停止」。

**屏幕预期**：立即结束，提示「已停止任务」；服务端返回 `cancelled: true`。

**解说**：
> 「长任务可中途中止。停止经 Connector 命令通道取消当前 job，是端到端可控的。」

---

## 场景 F｜上下文报告 + 运行评分卡（2 分钟，重点）

**操作（网页输入框）**：

```
读一下本项目 src/ 下所有 .py 文件，总结模块职责
```

**屏幕预期**：任务结束，对话流尾部出现「运行评分」四维度卡片（安全/过程/质量/效率）+ `process_hint`。

**操作**：点开「▸ 上下文报告（点击展开）」。

**屏幕预期**：表格 Zone/Source/Pri/Tokens/Used/Cited/Rate 有数据，能看到 `retrieval` / `session` 等 zone 的引用率。

**解说**：
> 「这是可观测性的两面。左边 run_score 四维度，事件统一进 EventBus，CLI 的 `/score` 和网页同源。右边上下文报告回答‘模型到底看了什么’——纯闲聊是空的，只有真正检索了文件、记忆才有数据，用来审计上下文是否被有效利用、有没有被注入误导。」

**回退对照**：再发一个闲聊「今天天气怎么样」，结束后展开上下文报告 → 显示「运行后才有数据」。说明报告非空的条件。

---

## 场景 G｜会话切换 / 新会话 / 删除（1.5 分钟，重点）

**操作**：

1. 输入框发：`用 Python 写一个计算斐波那契的函数`
2. 点顶部「新会话」
3. 输入框发：`用 Python 写一个快速排序`
4. 点左侧「会话」列表第一条（斐波那契）

**屏幕预期**：点回第一条后，切回斐波那契会话且历史消息还在，当前会话不丢。

**操作**：点某条右侧 `×` 删除。

**解说**：
> 「左侧是历史会话列表，点击切换、可删除。这里有个坑我们修过：早期版本点历史会话会切不进去、还丢当前会话——根因是 Connector 把会话写到了和服务器读取不同的目录。我们统一到 `DEFAULT_SESSION_DIR` 并给消息接口加了磁盘回退，切换和删除都正常工作了。」

## 场景 I｜Web → CLI 切换，长任务回滚（3 分钟，重点）

**操作（终端 2）**：

```bash
synapse          # 进入 REPL
```

**屏幕预期**：REPL 提示符，可输入。

**操作**：

```
/resume          # 恢复网页刚那个会话
```

**屏幕预期**：显示 `Resumed session <id> (N msgs)`，历史接续。

**解说**：
> 「网页和 CLI 共享同一套 Session 落盘格式，所以网页跑的任务在 CLI 里 `/resume` 能接着聊、接着干。」

**操作**：

```
/checkpoint before-refactor
```

（制造一点改动，例如让 Agent 「重构 auth 模块」跑偏后）

```
/rewind 1
```

**屏幕预期**：工作区被改的文件回滚到 checkpoint 状态；untracked 文件保留。

**解说**：
> 「这是长任务恢复路径。任务起点自动打 Git checkpoint（临时 index 快照，不碰你的暂存区和工作区）。thrashing 检测首次触发会自动回滚并提示换思路；`/rewind` 也能手动跨会话回滚。Agent 跑偏有‘后悔药’。」

---

## 场景 J｜CLI 关键能力补全（2 分钟）

**操作（终端 2，另起几个一次性演示）**：

```bash
# 全自动批准，不弹窗（等价于 Web auto）
synapse run --yes "批量把当前目录 *.txt 重命名为 *.md"

# 接入 MCP 外部工具
synapse run --mcp-server "fs:npx -y @modelcontextprotocol/server-filesystem ." "列出当前目录占用最大的 3 个文件"

# 续接旧会话
synapse run --resume "把上次的方案落地成代码"
```

**屏幕预期**：`--yes` 无确认直接执行；`--mcp-server` 接入 filesystem 工具并完成任务；`--resume` 追加到旧历史。

**解说**：
> 「CLI 端能力更全：`--yes` 非交互全自动、`--mcp-server` 接外部工具协议、`--enable-external-tools` 开 HTTP/DB/Browser、`--mode` 切四种规划器。Web 端为了安全默认关外部工具，CLI 给熟练用户完整开关。」

---

## 场景 K｜评测闭环（2 分钟，重点）

**操作（终端 1 或新终端）**：

```bash
synapse eval process_quality
```

**屏幕预期**：跑内置 fixture，结束生成 `eval-results/process_quality-<ts>.json` + HTML + CSV。

**操作（可选扩展）**：

```bash
synapse eval repo_pytest --max-tasks 5 --repeat 3 --report eval-results/repo.json
synapse eval.visualize eval-results/repo.json
```

**屏幕预期**：多任务多重复，报告含 Pass@k 与 95% CI；`visualize` 出双语 Dashboard。

**解说**：
> 「评测不是只看最后一句 SUCCESS。它验证 Agent→workspace→grader→report 完整链路，输出 Pass@k + 置信区间 + Token/成本，且按 repository cluster 重采样避免同仓库多题被当独立证据。JSON 是事实来源，HTML 不改统计口径。我们明确区分 fixture 验证链路和官方 benchmark 成绩，不夸大。」

---

## 场景 L｜收尾（1 分钟）

**解说**：
> 「总结一下：Synapse 把 Agent 的工程复杂度收敛到一组可替换的协议接口上——LLM/Tool/Memory/Planner 都是接口，换实现不改业务代码；安全是动作时、Web/CLI 一致；可观测用统一事件源；评测可复现。这就是它的核心价值。」

---

## 裁剪建议

- **只讲 5 分钟**：A → B → C → D(确认弹窗) → F(评分+上下文) → L。
- **偏架构**：B → D → F → I(回滚) → K(评测)。
- **偏安全**：D(三种授权+记忆+auto) → G 的修复故事 → I 的回滚。
- **偏工程闭环**：C → F → I → K。

## 翻车预案

- 模型 key 失效：提前 `synapse` 验证能回复；演示前空跑一句「你好」。
- 网页起不来：确认端口未被占，或换 `--port 8001`。
- 上下文报告空的：用 F 里的「读 src/ 下所有 .py」这类真正检索的命令，别用闲聊。
- `/rewind` 无 checkpoint：先 `/checkpoint` 再制造改动；非 git 仓库会提示不可用。
