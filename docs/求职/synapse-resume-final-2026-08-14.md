# Synapse：面向代码仓库长任务的本地 Code Agent Harness

> 个人项目

## 项目描述

仓库级长任务中的 Code Agent 容易出现上下文膨胀、执行状态断裂和工具副作用失控，且模型自报“完成”难以验证。Synapse 作为模型与开发环境之间的本地 Harness，统一治理任务执行、状态持久化与结果验证，使长任务可控、可恢复、可复盘。

## 核心职责与贡献

1. **上下文治理**：针对历史消息与无关仓库内容持续挤占上下文，设计 Git-aware 检索、符号提取、分区预算与 compaction；将注入内容约束在 Token 预算内，检索异常时可降级继续执行。

2. **记忆与任务恢复**：针对多轮事实丢失、重复探索和中断后从头执行，按生命周期拆分 Session / Project / User / Semantic 记忆，结合原子持久化与 workspace drift 校验；支持跨进程续接，并避免不同项目的规则相互污染。

3. **工具安全治理**：针对静态风险标签无法识别具体调用的真实副作用，在 action-time 校验命令链、重定向、敏感路径和工作区边界；越界或高风险操作在执行前被拦截或转入确认，关键行为可审计。

4. **建立可复现的分层评测与治理闭环**：针对模型自报成功、单次跑通和同仓库样本相关性导致的结论偏差，串联 EventBus、completion gate、隔离 workspace、外部 grader、配对实验与 repository-cluster 统计，并以冻结 manifest、预注册和不可变 run registry 固化证据；统一区分 4 类验证状态、5 类持续监控指标，使 Agent、Harness、grader 与基础设施故障可分层定位。
