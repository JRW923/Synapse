# Synapse：面向代码仓库长任务的本地 Code Agent Harness

> 个人项目

## 项目描述

面向代码仓库长链路任务构建本地Code Agent Harness，作为模型与真实开发环境之间的运行时控制层，统一治理上下文、记忆、工具执行和结果验证，解决多轮执行中的信息膨胀、状态丢失、越界操作及结果不可验证问题。

## 核心职责与贡献

1. 完善长任务上下文治理机制：为避免历史消息和无关文件挤占预算、仓库内容重复读取，采用Git-aware检索、符号提取、相关性排序、四区预算与摘要式compaction；按配置的Token预算注入内容，检索故障默认最多阻塞10s

2. 构建分层记忆与任务恢复体系：为解决跨轮事实丢失与中断重跑，采用原子持久化、/resume续接与Git快照回滚；状态拆为Session、Project、User、Semantic四类，会话跨进程恢复，项目规则与用户偏好支持跨任务复用

3. 建立工具调用安全与执行治理机制：因静态Tool风险声明无法识别参数副作用，采用action-time鉴权，按工作区、shlex命令链、重定向与SSRF判险；覆盖5级风险决策、14类危险命令模式和12类敏感路径，高风险操作执行前拦截或确认

4. 建立冻结数据与外部grader评测链：针对模型自报成功不可信，以completion gate、隔离workspace与重复统计；SWE-bench冻结20题gold子集三模型×3评测，success@3达40%-55%、误报率58%-77%

## 使用边界

已完成冻结 20 题子集（gold-verified 入库）上三档模型 × 3 次重复的正式 run，但样本量（n=20）与第三方网关口径不支持模型或 Harness 能力排名：各模型 CI 重叠大，数字用于证明"评测链路与治理机制可产出可信结果"，不表述为官方榜单成绩。运行时架构（Protocol + IoC + EventBus、6 Provider / 4 Planner / 2 MCP 传输、零主循环扩展）见[扩展指南](../开发/扩展指南.md)与 `examples/extensions/`，在"一分钟讲解"中口头展开。
