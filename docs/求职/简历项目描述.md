# Synapse：面向代码仓库长任务的本地 Code Agent Harness

> 个人项目

## 项目描述

仓库级长任务中的 Code Agent 容易出现上下文膨胀、执行状态断裂和工具副作用失控，且模型自报“完成”难以验证。Synapse 统一治理任务执行、状态持久化与结果验证，使长任务可控、可恢复、可复盘。

## 核心职责与贡献

1. **以分区预算和 Git-aware 检索治理上下文**：针对历史消息与无关仓库内容持续挤占上下文，引入符号提取、分区预算和 compaction；检索异常时自动降级，保证任务持续执行。
2. **以分层记忆和漂移校验恢复长任务状态**：针对多轮事实丢失、重复探索和中断后从头执行，按 Session / Project / User / Semantic 生命周期拆分记忆，并结合原子持久化与 workspace drift 校验；支持跨进程续接，避免项目规则相互污染。
3. **以 action-time 授权治理工具副作用**：针对静态风险标签无法识别具体调用的真实副作用，在执行时校验命令链、重定向、敏感路径和工作区边界；越界或高风险操作被拦截或转入确认，关键行为可审计。
4. **以冻结数据和外部 grader 建立评测证据链**：针对模型自报成功、单次跑通和同仓库样本相关性导致的结论偏差，串联 completion gate、隔离 workspace、配对实验和 repository-cluster 统计，并用 manifest、预注册与不可变 run registry 固化证据；可分层定位 Agent、Harness、grader 与基础设施故障。

## 使用边界

评测框架和单题官方 smoke 已验证，但尚未完成多任务、重复的跨 Harness 统计实验。因此简历不应写 Harness 或模型能力提升百分比；可将评测能力表述为“具备可复现的评测与治理机制”。
